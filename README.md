# 카톡 예약 발송

하랑마케팅에서 만든 PC 카카오톡용 단체 발송 · 예약 발송 프로그램입니다.
거래처, 고객, 회원 채팅방 수십 곳에 같은 공지를 한 번에 보내거나 원하는 시각에 예약해 둘 수 있습니다.
보험 · 자동차 딜러 · 대행사처럼 채팅방이 많은 분들을 위해 만들었습니다.

PC 에서 여세요. 윈도우 PC 카카오톡용 프로그램이라 휴대폰에서는 받아도 쓸 수 없습니다.

바로 내려받기 : https://github.com/jty0221-dot/kakao-sender/releases/latest/download/KakaoSender.zip

누르면 압축 파일이 바로 받아집니다. 이 주소는 늘 가장 새 버전을 내려줍니다.
공지 : 이 저장소의 공지.json 에 적힙니다. 프로그램 왼쪽 공지 칸에서도 같은 내용이 보입니다.


## 1. 설치

압축을 풀고 KakaoSender.exe 를 실행합니다. 따로 설치할 것은 없습니다.
PC 카카오톡이 켜져 있고 로그인돼 있어야 합니다. 프로그램은 카카오톡 로그인을 대신하지 않습니다.
같은 폴더의 판매설정.json 은 가격과 연락처 안내 파일입니다. 지워도 프로그램은 돕니다.

윈도우가 알 수 없는 앱이라고 막으면 추가 정보를 누른 뒤 실행을 누릅니다. 서명 비용을 아껴 값을 낮춘 것이라 뜨는 경고입니다.


## 2. 처음 쓰는 순서

첫째, 클라이언트 탭에서 보낼 방을 올립니다.
업체명과 카톡 방 이름을 넣습니다. 방 이름은 카카오톡 채팅방 이름과 글자까지 똑같아야 합니다.
엑셀이나 메모장에 한 줄에 업체명, 방 이름 순으로 적은 파일을 불러올 수도 있습니다.

둘째, 전체 열기 확인을 한 번 누릅니다.
프로그램이 방을 하나씩 검색해서 열었다 닫습니다. 아무것도 보내지 않습니다.
못 연 방은 빨간색으로 표시되니 방 이름을 고칩니다. 방 하나에 2초에서 4초 걸립니다.

셋째, 보내기 탭에서 방을 고르고 글을 씁니다.
지금 보내기를 누르면 확인창이 뜨고, 확인을 누르면 바로 나갑니다.
예약 등록을 누르면 예약 목록에 들어가고, 거기서 승인을 눌러야 시각에 나갑니다.

넷째, 예약을 쓰려면 오른쪽 위 자동 발송 스위치를 켭니다.
승인한 건이 시각이 되면 이 PC 의 카카오톡으로 나갑니다. 프로그램 창이 떠 있고 PC 가 켜져 있어야 합니다.


## 3. 보내는 동안

방을 열고 붙여넣고 엔터를 누르는 일을 프로그램이 대신하는 것이라, 보내는 동안 마우스와 키보드를 건드리지 않습니다.
건드리면 글이 엉뚱한 창에 들어갈 수 있습니다. 방 하나에 3초 정도 걸립니다.
멈춤 버튼을 누르면 지금 방까지만 보내고 섭니다.


## 자주 쓰는 기능 (1.9.0 기준)

이름 넣어 보내기 : 보내기 화면의 이름 넣기 버튼을 누르면 글에 이름 자리가 들어갑니다. 받는 방마다 클라이언트 목록의 이름으로 바뀌어 나가서 1:1 방에도 따로 쓴 것처럼 보낼 수 있습니다. 업체명, 날짜, 요일도 같은 방식으로 넣을 수 있습니다.
보내기 전 점검 : 목록에 없는 방, 이름이 님님으로 겹치는 방, 두 번 고른 방을 확인창에서 알려 줍니다. 한 방에 시험 버튼으로 하나에만 먼저 보내 볼 수 있습니다.
전송 현황 : 지금 보내기를 누르면 방마다 보냄, 확인 불가, 실패가 바로 보입니다. 방 사이 간격은 2초에서 60초까지 정합니다.
문구 저장 : 자주 쓰는 글을 이름 붙여 저장하고, 최근 보낸 글과 함께 문구 불러오기에서 골라 씁니다.
반복 : 한 번, 매일, 매주, 매월, 며칠마다 중에서 고릅니다. 실패한 방만 골라 다시 보낼 수 있고, 발송 이력과 월간 발송 보고서를 CSV 로 내보냅니다.
고객 관리 : 클라이언트 화면에서 찾기, 그룹별 보기, 여러 방 그룹 한 번에 지정이 됩니다. 예약 여러 건을 CSV 파일로 한 번에 등록할 수도 있습니다.
연결 : 연결 · 설정 메뉴에서 다른 프로그램이나 구글 시트로 예약을 받아 대기로 쌓을 수 있습니다. 들어온 예약도 승인해야 나갑니다. 구글 시트는 예약 탭 하나만 웹에 게시하고, 방 이름에 손님 이름이 들어갈 수 있으니 예약 전용 파일을 따로 만드세요.
광고 글 : 광고 글로 체크하면 맨 앞에 광고 표기와 끝에 수신거부 안내가 붙고, 광고 수신에 동의한 방에만 갑니다. 밤 9시부터 아침 8시 사이 광고는 경고합니다.
결과 보고 : 연결 · 설정에 내 방 이름(나와의 채팅)을 넣어 두면 보내기가 끝날 때마다 성공과 실패를 그 방으로 알려 줍니다.

정품은 기간제입니다. 기간 안에는 방 수와 건수 제한이 없습니다. 전부 부가세 포함입니다.

## 5. 정품키 받는 순서

1) 프로그램 왼쪽 요금 칸의 구매 · 문의 버튼을 누릅니다
2) 1번에서 요금제를 고릅니다
3) 3번의 카카오톡 문의하기를 누릅니다. 기기 코드와 고른 요금제가 적힌 문의 글이 복사되고 카카오톡 채팅창이 열리니 붙여 넣기만 하면 됩니다
4) 입금이 확인되면 카카오톡으로 정품키를 보내드립니다. 받은 정품키를 4번 칸에 붙여 넣고 인증하기를 누릅니다

정품키는 기기 코드 하나에만 맞습니다. 다른 PC 에서는 쓸 수 없고, PC 를 바꾸면 새 기기 코드를 보내 주시면 추가 비용 없이 다시 발급합니다.
이미 인증된 상태에서 새 정품키를 넣으면 기간이 이어서 늘어납니다.


## 추천 포인트

1.7.0 부터 구매 · 문의 창에 내 추천 코드와 소개 문구 복사 버튼이 있습니다. 추천 코드는 R 로 시작하는 여섯 글자이고 PC 마다 자동으로 정해집니다. 가입은 없습니다.
소개받은 분이 결제할 때 추천인 코드를 적으면 결제액의 20% 가 추천인 포인트로 쌓입니다. 1점은 1원입니다.
5,500점마다 정품 기간 30일을 늘려 드리고, 30,000점부터는 1점당 0.8원으로 현금 환전해 드립니다. 사업자등록이 있으시면 세금계산서로, 아니시면 관련 세금을 떼고 보내 드리며, 필요한 정보는 환전 때 따로 여쭙니다.
추천은 한 단계만입니다. 소개받은 분이 다시 소개해도 처음 추천인에게는 쌓이지 않고, 내 코드를 내 결제에 쓸 수는 없습니다.
포인트 잔액 확인 · 연장 · 환전은 카카오톡 채널로 내 추천 코드를 보내 주시면 처리해 드립니다.
소개하실 때는 포인트를 받는다는 사실을 밝혀 주세요. 소개 문구에 그 문장이 들어 있으니 지우지 말고 보내 주시면 됩니다.

맨 위 바로 내려받기 주소에서 새 압축 파일을 받아 풀고, 지금 쓰는 KakaoSender.exe 자리에 덮어쓰면 됩니다.
정품 인증, 클라이언트 목록, 예약, 기록은 전부 그대로 남습니다.

## 8. 알아 둘 것

카카오톡이 업데이트되면 창 구조가 바뀌어 프로그램이 방을 못 찾을 수 있습니다. 그때는 연락 주시면 맞춰 드립니다.
광고성 글을 동의 없이 보내는 것은 정보통신망법에 걸립니다. 받는 분이 동의한 방에만 보냅니다.
프로그램은 카카오톡 계정 정보를 저장하지 않습니다. 인터넷은 이 저장소의 공지와 새 버전 안내를 읽어 오는 데만 씁니다.
기기 코드, 방 이름, 보낸 글은 PC 밖으로 나가지 않습니다. 모든 기록은 PC 의 logs 폴더와 data 폴더에만 남습니다. 보낸 방 기록은 7일치만 남고 오래된 것은 저절로 지워집니다.
